# Videographer Business Management System (Java Swing)

A standalone, offline desktop application built using an AI-assisted development workflow during the **Java CodeCraft 2026** bootcamp at CHRIST (Deemed to be University), Bangalore.

## Features
- **Dashboard:** Live overview of total bookings, revenue, pending payments, and upcoming events.
- **Customer & Booking Management:** Manage client records, multi-day shoot dates, pricing, and advance/balance tracking.
- **Availability Checker:** Prevents double-booking conflicts on occupied dates.
- **100% Standalone & Local:** Runs locally on Java Swing with in-memory/local storage—no external database or internet connection required.

## How to Run
1. Open the `src` folder in Eclipse or any Java IDE (or compile via `javac` and run the main class).
